# `craftty`


We're a community of developers obsessed with crafting awesome terminal apps that are designed from the ground up to take advantage of modern terminal features.

## Why ?

Modern (GUI) apps usually bring along a lot of resource usage (which is not an issue if you're on maxed out specs) and we understand that
not everyone is running a fast PC. Terminal apps are more friendly with budget hardware, load faster and more oriented towards
keyboard interaction.

By bringing the apps we rely on daily to the terminal, we are reducing the surface area for context switching which disrupts
focus. 

If it can run in a terminal, **run it in the terminal**.

## How ?

Code output is no longer the bottleneck in programming, creativity and review is where the work now lies.
By focusing on prototyping the concept, we get from idea to binary much faster, test what works and add enhancements
until we reach a point of "feature completion", where no more agentic coding will be used.

Afterwards, the code is human reviewed, module for module, to give the code a better structure that humans can maintain
and extend in the future. 

The human stays in the loop.

## Projects


> [!note]
> Currently all the apps are in beta and more are coming soon...

- [gtm](https://github.com/craftty-org/gtm) - Cross platform, feature rich and hackable terminal audio player 📻 
   - [gtm.nvim](https://github.com/craftty-org/gtm.nvim) - 🤏 Tiny client for gtmd bringing support for playback control, reactive theming and statusline integration in Neovim
- [gtw](https://github.com/craftty-org/gtw) - Cross platform terminal client with rich media preview and local caching for Wikipedia 🗺.
- [aoc-tui](https://github.com/craftty-org/aoc-tui) - A TUI client for Advent of Code (AOC) which allows you to solve AOC challenges from the terminal and submit them. You can also access previous year's challenges
